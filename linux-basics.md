## 2. Структура каталогов
* `/bin` — основные бинарные файлы (команды)
* `/etc` — конфигурационные файлы системы
* `/var` — изменяемые данные (логи, базы данных)
* `/usr` — пользовательские программы и утилиты
* `/home` — домашние директории пользователей
* `/tmp` — временные файлы

## 3. Навигация и просмотр
* `ls -la` — показать все файлы (включая скрытые) с подробностями
* `cd` — сменить директорию
* `pwd` — узнать текущий путь
* `cat` / `less` — просмотр содержимого файлов
* `head` / `tail` — просмотр начала/конца файла

## 4. Управление файлами и папками
* `mkdir` — создать папку
* `touch` — создать пустой файл
* `cp` — копировать
* `mv` — переместить / переименовать
* `rm -rf` — удалить (осторожно!)
